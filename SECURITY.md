# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | Yes                |
| < 0.5   | No                 |

## Reporting a Vulnerability

Security issues and vulnerabilities should be reported privately to the maintainers rather than through public issue trackers.

Please report vulnerabilities via email to:
`mansi.p.dhruv@gmail.com`

Please include:
- A description of the vulnerability and potential attack vectors.
- Steps to reproduce or a minimal proof of concept.
- Affected versions or components.

We will acknowledge receipt within 48 hours and work with you on disclosure and patch validation.
